# Emerald Calculator

A modern desktop calculator built with Python and Tkinter.

## Features

- Dark-themed interface
- Basic arithmetic, parentheses, percentage, and sign toggle
- Mouse and keyboard input, including the numeric keypad
- Windows high-DPI awareness

## Requirements

- Python 3.10 or later
- Tkinter (included with most standard Python installations)

## Run

```powershell
python calculator.py
```

## Keyboard shortcuts

- `Enter` or `=`: calculate
- `Backspace`: delete the last character
- `Escape`: clear
- Numeric keypad: numbers and arithmetic operators
